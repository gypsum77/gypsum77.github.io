자극에 따른 반응의 경로

의식적 반응 vs 무조건 반사 · 142쪽

구분의식적 반응무조건 반사
뜻대뇌의 판단 과정을 거쳐 자신의 의지에 따라 일어나는 반응대뇌의 판단 과정을 거치지 않아 자신의 의지와 관계없이 일어나는 무의식적 반응
중추대뇌척수, 연수, 중간뇌
특징판단 과정이 복잡할수록 반응이 나타나는 데 시간이 더 걸린다매우 빠르게 일어나 위험한 상황에서 몸을 보호하는 데 중요한 역할을 한다
예주전자를 들고 컵에 물을 따름 · 손이 시린 것을 느끼고 장갑을 낌 · 날아오는 공을 보고 야구 방망이를 휘두름 척수: 뜨겁거나 날카로운 물체에 닿았을 때 몸을 움츠림, 무릎 반사
연수: 재채기, 딸꾹질, 침 분비
중간뇌: 동공 반사
의식적 반응 — 주전자를 들고 컵에 물을 따를 때 자극 → 감각 기관(눈) → 감각 신경(시각 신경) → 대뇌 → 척수 → 운동 신경 → 반응 기관(팔의 근육) → 반응
무조건 반사 — 뜨거운 주전자에 손이 닿아 급히 뗄 때 자극 → 감각 기관(피부) → 감각 신경(피부 감각 신경) → 척수 → 운동 신경 → 반응 기관(팔의 근육) → 반응
얼굴 vs 팔·다리 얼굴에서 받아들인 자극은 척수를 거치지 않고 바로 대뇌로, 팔이나 다리에서 받아들인 자극은 척수를 거쳐 대뇌로 전달된다.

호르몬 이상질병증상
생장 호르몬소인증 (성장기, 결핍)키가 정상인에 비해 매우 작다
거인증 (성장기, 과다)키가 정상인에 비해 매우 크다

티록신갑상샘 기능 저하증 (결핍)쉽게 피로해지고, 추위를 잘 타며, 체중이 증가한다

인슐린당뇨병 (결핍)쉽게 피로해지고, 체중이 감소하며, 오줌에 당이 섞여 나오고 심한 갈증을 느낀다

항상성 — 체온 · 혈당량 · 수분량

몸 안팎의 환경이 변해도 적절하게 반응하여 몸의 상태를 일정하게 유지하는 성질(신경·호르몬) · 144쪽

체온 조절 · 중추: 간뇌 — 더울 때 체온 높아짐 → 간뇌 → 피부 근처 혈관 확장 + 땀 분비 증가(기화열로 열 흡수) → 열 방출량 증가 → 체온 낮아짐
체온 조절 — 추울 때 체온 낮아짐 → 간뇌 → 피부 근처 혈관 수축(열 방출량 감소) + 근육 떨림 · 뇌하수체 → 갑상샘 자극 호르몬 ↑ → 갑상샘 → 티록신 ↑ → 세포 호흡 촉진 → 열 발생량 증가 → 체온 높아짐
체온열 방출량열 발생량
더울 때피부 근처 혈관 확장, 땀 분비 증가 → 증가—
추울 때피부 근처 혈관 수축 → 감소근육 떨림, 세포 호흡 촉진 → 증가
혈당량 조절 — 높을 때 혈당량 증가 → 이자에서 인슐린 분비 → 간에서 포도당을 글리코젠으로 합성해 저장 + 세포에서 포도당 흡수 촉진 → 혈당량 감소
혈당량 조절 — 낮을 때 혈당량 감소 → 이자에서 글루카곤 분비 → 간에서 글리코젠을 포도당으로 분해해 혈액으로 내보냄 → 혈당량 증가
몸속 수분량 조절 — 감소할 때 땀을 많이 흘림 → 뇌하수체에서 항이뇨 호르몬 분비 증가 → 콩팥에서 물의 재흡수 촉진 → 오줌량 감소
몸속 수분량 조절 — 증가할 때 물을 많이 마심 → 뇌하수체에서 항이뇨 호르몬 분비 억제 → 콩팥에서 물의 재흡수 감소 → 오줌량 증가
